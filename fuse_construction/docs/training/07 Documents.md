# Documents

*The project document register — Fuse Construction user guide 07*

**Construction → Documents → New.** Give it a title and number, the project and the type:
drawing, specification, method statement, ITP, transmittal, submittal, RFI, NCR, technical
query, site instruction, permit, certificate, contract or correspondence.

Set who it is **from** and **to** — a supplier, client, employee or the company — attach the
file and **Submit** to issue it. It goes to **Under Review**.

After issue the **status** and the **response** stay editable: an RFI is answered, a drawing
approved, an NCR closed.

## A new revision

Cancel the issued document and press **Amend**. The revision steps on (0 → 1, A → B) and, when
the new one is issued, the old one is marked **Superseded**. Every revision stays on record.
